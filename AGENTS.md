# local-lab — правила для агентов

Свежий репозиторий лаборатории. Старт намеренно пустой: прежний проект
(`theseus-local-lab`, локальная папка `life-science-research-plugin-life-science-4`)
остаётся справочным архивом и сюда не переносится.

## Карта

| Путь | Что |
|---|---|
| `IDEA.md` | замысел проекта, короткая заметка |
| `docs/agents/` | конфигурация инженерных скиллов: issue tracker, triage-лейблы, доменные доки |

## Правила

- Один смысл — одно место. Дублирующие описания не добавлять.
- Файл появляется вместе с причиной: сначала задача, потом содержимое.
- Секреты в репозиторий не попадают; ключи живут в окружении.
- Мусор прошлого проекта (рабочие каталоги, архивы, вендорные копии) сюда не копируется.
