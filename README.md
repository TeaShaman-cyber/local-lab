# local-lab

Новая лаборатория с чистого листа. Заменяет legacy-репозиторий
`theseus-local-lab`, который накопил противоречия и стал тяжёлым в поддержке.

- Замысел: [`IDEA.md`](IDEA.md)
- Правила для агентов: [`AGENTS.md`](AGENTS.md)
- Задачи: GitHub Issues этого репозитория

## Скиллы

Проектные скиллы лежат в `.agents/skills/` и являются источником правды.
Hermes читает только `$HERMES_HOME/skills/`, поэтому установка — копией:

```bash
scripts/sync-skills.sh
```

Скрипт перезаписывает `$HERMES_HOME/skills/local-lab/` и печатает readback
(source vs installed), чтобы расхождение было видно, а не предполагалось.

Принцип: в репозиторий попадает только то, что живо сейчас. Пилоты, рабочие
каталоги и архивы прошлого проекта остаются вне его.
